TUNGAahui Digital Book Library

Энэ хувилбар нь books.tungaahui.mn-ийг олон номтой Digital Book Library болгоно.

Одоогийн ном:
- URL: /privacy
- PDF: Redbook2.pdf

Шинэ ном нэмэх:
1. PDF-ээ repository-ийн үндсэн хавтсанд upload хийнэ.
2. index.html доторх `const books = [...]` жагсаалтад шинэ номын 1 объект нэмнэ.
3. slug нь URL болно. Жишээ: slug: "ev" -> https://books.tungaahui.mn/ev
4. GitHub дээр commit хиймэгц Vercel автоматаар deploy хийнэ.

Файлууд:
- index.html
- vercel.json

Анхаарах зүйл:
- Redbook2.pdf одоо байгаа repository-дээ хэвээр үлдэнэ.
- vercel.json нь /privacy зэрэг URL-уудыг index.html рүү чиглүүлэхэд хэрэгтэй.
